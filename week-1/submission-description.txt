This Week 1 report presents the project planning and system architecture for TaskNest, a proposed full stack web application for managing personal projects and tasks. The application is intended for students and early career professionals who need one place to organize work, track deadlines and review progress.

The report defines the project purpose, objectives, minimum viable product and scope boundaries. The planned features include account registration, sign in, private project management, task creation and editing, status and priority filters, title search and dashboard summaries. Clear acceptance conditions explain the expected behavior of each major feature.

User interaction flowcharts show authentication and task creation, including validation failures and recovery paths. Detailed desktop and mobile wireframes cover the landing page, account forms, dashboard, project detail and task editor. The document also describes responsive layouts, keyboard accessibility, loading feedback, empty states and error handling.

The proposed architecture uses React for the frontend, Node.js with Express for the backend and PostgreSQL for persistent storage. The architecture diagram explains communication between the browser, API layers and database. A relational schema defines users, sessions, projects and tasks, with primary keys, foreign keys, constraints and ownership relationships. The API contract identifies request methods, endpoints, inputs, responses and error conventions.

Design decisions are supported by practical reasons, including keeping the initial scope manageable, protecting user data and simplifying future integration. Security planning covers password hashing, session cookies, CSRF protection, input validation and authorization. The report concludes with quality targets, planned validation scenarios and a six week repository roadmap. This submission covers Week 1 planning and design only; application development and runtime testing remain scheduled for later weeks.
