For Week 3 of the Junior Full Stack Developer Intern internship, I developed the backend API for TaskNest, a personal project and task management application. The implementation provides RESTful endpoints for account registration, login, logout, session retrieval, project management, task management, and dashboard summaries. Project and task resources support create, read, update, and delete operations, with consistent JSON responses and appropriate HTTP status codes.

The backend uses Node.js and Express with a relational PostgreSQL schema. A file-backed embedded PostgreSQL engine provides persistent local storage without requiring a separate database installation. An additional adapter supports a separate PostgreSQL server. Users, sessions, projects, and tasks are linked through foreign keys, and deleting a project removes its associated tasks. SQL parameters are bound rather than assembled from user input.

Authentication uses Argon2id password hashes and opaque session cookies. Session tokens are hashed before database storage, and authentication rotates both the session and CSRF token. Mutation requests require a CSRF token and an allowed Origin. Every project and task operation checks ownership. Validation rejects unsupported fields, invalid dates, incorrect types, and oversized input. Rate limits, controlled error messages, and security headers provide additional protection.

The API also supports combined task filters, pagination, and owner-specific dashboard totals. Verification includes 30 passing automated tests using real HTTP requests and real PostgreSQL databases, including persistence after restart. A separate live walkthrough exercises all 16 endpoint and method combinations. The submission includes source code, setup instructions, a database schema, API documentation, an OpenAPI specification, recorded test evidence, and a Word report. This submission covers the Week 3 backend; frontend integration remains a later task.
