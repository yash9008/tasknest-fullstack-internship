# Manual Week 3 submission

This is **Junior Full Stack Developer Intern**, not the separate Frontend Web Developer internship.

1. Open your existing `tasknest-fullstack-internship` GitHub repository. Keep the earlier week folders.
2. Extract `TaskNest-Week-3-Submission.zip`. In the extracted `tasknest-fullstack-internship` folder, drag the **whole `week-3` folder**, along with the updated root `README.md`, into GitHub's **Add file → Upload files** screen at the repository root. Check that paths start with `week-3/`, not `tasknest-fullstack-internship/week-3/` or `week-3/week-3/`. If a placeholder `week-3/README.md` already exists, replace it with the new one.
3. Commit message: `Add TaskNest Week 3 backend API`.
4. Confirm that `week-3/src`, `week-3/tests`, `week-3/schema.sql`, `week-3/pnpm-lock.yaml`, and `week-3/docs` are visible. Hidden `.gitignore` and `.env.example` are included in the archive; show hidden files in Finder with Command+Shift+Period if needed. Do not upload node_modules, a data directory, or a real `.env`.
5. On the YuvaIntern **Week 3 Back-End API Development** form, select `TaskNest-Week-3-Report.docx` as the report. The report field accepts Word files, so do not put the ZIP there. The ZIP contains the code deliverable; GitHub provides access to the extracted source.
6. Paste the Week 3 GitHub folder URL after uploading. If your account, repository and branch use the names above:

   `https://github.com/yash9008/tasknest-fullstack-internship/tree/main/week-3`

   Copy the actual folder URL from your browser if any name differs. This link is an expected destination, not confirmation of an upload.
7. Paste all text from `submission-description.txt` into the report description. It exceeds the portal's 200-word minimum.
8. Review the selected internship and week, then submit yourself. No account access is needed for this handoff.
