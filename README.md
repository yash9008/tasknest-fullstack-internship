# TaskNest — YuvaIntern Full Stack Internship

TaskNest is a proposed private project and task tracker. This repository contains the Week 1 planning and architecture submission for the **Junior Full Stack Developer Intern** internship.

## Week folders

| Week | Focus | Status |
| --- | --- | --- |
| [Week 1](week-1) | Project planning and system architecture | Design documented |
| [Week 2](week-2) | Frontend application development | Not started |
| [Week 3](week-3) | Backend API development | Not started |
| [Week 4](week-4) | Frontend and backend integration | Not started |
| [Week 5](week-5) | Testing, debugging and optimization | Not started |
| [Week 6](week-6) | Deployment, maintenance and reflection | Not started |

## Week 1 deliverables

- [Word report](week-1/TaskNest-Week-1-Report.docx) — the single file to upload to the portal.
- [Readable report](week-1/REPORT.md) — project brief, requirements, diagrams, wireframes, API contract and rationale.
- [Diagrams](week-1/diagrams) — six original planning figures embedded in the report.
- [Schema design](week-1/schema.sql) — proposed PostgreSQL schema, not a deployed database.
- [Submission description](week-1/submission-description.txt) — more than 200 words for the portal.

## Planned stack

React, Node.js, Express and PostgreSQL. Only planning artifacts are included. There is no application to install or run yet, and no runtime testing or deployment is claimed.

Later folders intentionally contain only placeholder README files. They preserve the six week structure without presenting later work as completed.
